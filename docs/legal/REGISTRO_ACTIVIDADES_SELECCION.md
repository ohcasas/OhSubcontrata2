# Justificación de no realizar Evaluación de Impacto (art. 35)

No se considera obligatoria, a validar con asesoría, porque:
1. No hay decisiones automatizadas ni perfilado con efectos jurídicos: decide siempre una persona.
2. No se tratan categorías especiales de forma sistemática ni a gran escala.
3. El volumen previsto es reducido y el acceso está limitado a una persona.
4. No se usan tecnologías de IA para cribar candidatos.

**Se revisará esta conclusión** si cambia alguno de estos puntos (por ejemplo, IA para cribar CV, más usuarios con acceso o mayor volumen).
